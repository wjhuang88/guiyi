# AI agent operation SOP

1. Create a session with objective, working set, permissions, and action budget.
2. Discover relevant tools from the catalog.
3. Query the semantic project state instead of scanning arbitrary files.
4. Dry-run every destructive or broad change.
5. Apply one coherent transaction.
6. Run validation immediately.
7. Repair or roll back when errors increase.
8. Run build and preview gates before completion.
9. Produce a final summary referencing transaction IDs and remaining diagnostics.

Content agents must not receive code-edit, external-process, commit, or publish permissions by default.
