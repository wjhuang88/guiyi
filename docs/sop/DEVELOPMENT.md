# Development SOP

1. Select a Ready Story from the product backlog.
2. Read related reference and ADR files.
3. Run baseline gates.
4. Add a failing test or reproducible validation.
5. Implement the smallest vertical change.
6. Run local gates after every acceptance point.
7. Update machine-readable diagnostics and tool descriptors.
8. Update reference documentation.
9. Produce a validation report and rollback notes.
10. Merge only after all gates pass.

No implementation task may begin without a Story ID. Scope discoveries become new backlog items rather than silent expansion.
