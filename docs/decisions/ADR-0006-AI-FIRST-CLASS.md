# ADR-0006: AI is a first-class client

- Status: Accepted
- Date: 2026-07-28

## Context

GUIYI Engine is an AI-native Bevy infrastructure project for tactical RPG production.

## Decision

Every core capability must be callable and discoverable without UI.

## Consequences

Makes pure-AI production possible and keeps UI optional.

## Validation

The decision is represented by workspace boundaries, public APIs, examples, tests, or repository gate scripts.
