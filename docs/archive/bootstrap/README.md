# GUIYI Engine 项目指导文档

> 本文档包用于将《归一》项目中已经形成的 Bevy 工程经验、内容管线、文档治理和开发 SOP，抽取为一个独立推进的游戏引擎基础设施项目。

## 项目定位

GUIYI Engine 不是通用 3A 游戏引擎，也不是《归一》的专用编辑器。

它的目标是成为一套面向以下游戏类型的、可独立演进的 Bevy 基础设施：

- 回合制战术 RPG
- 区域探索与关卡切换
- 剧情、任务和事件驱动
- 数据化角色、技能、物品和遭遇
- 面向策划、关卡、剧情和美术协作的内容生产
- 支持独立预览、验证、构建和发布

《归一》是第一个接入项目，也是首个真实验证项目。

## 推荐使用方式

1. 在新仓库根目录建立 `docs/`。
2. 将本文档包放入 `docs/bootstrap/`。
3. 先批准项目章程和架构边界。
4. 再依据 `INITIAL-BACKLOG.md` 启动 Iteration 001。
5. 每个实施任务都必须引用一个 Story ID，并执行对应质量门禁。
6. 《归一》仓库只作为消费方和验证方，不再承担引擎基础设施的长期演进。
