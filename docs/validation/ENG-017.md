# ENG-017 validation

## Implemented behavior

Runtime Stage loading now validates the complete artifact contract before any ECS mutation. `ArtifactEnvelope::new` calculates a dedicated artifact checksum over envelope identity, compatibility metadata, source hash, and payload. The runtime rejects missing or mismatched checksums rather than treating `source_hash` as payload integrity evidence.

`StageRuntimeManager` verifies the expected Stage artifact type, supported compiler version, checksum, payload shape, metadata shape, unique runtime object IDs, and required object properties. Runtime errors expose stable codes and structured context. Preview renders these structured failures when JSON output is requested.

## Atomicity evidence

Tests confirm that wrong type, unsupported version, checksum corruption, malformed payload, duplicate object IDs, and an invalid object appearing after a valid object all leave both world entity count and active Stage count unchanged. Validation completes before instance allocation and spawning.

The existing 100-cycle load/unload regression and global-entity preservation regression remain green.
