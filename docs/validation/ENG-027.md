Positive cases include full 40-character Action pin, pinned reusable workflow and concrete toolchain version. The ordinary `python3 scripts/check_reproducibility.py` checks the actual files (and all workflow files, not just the original CI) and fails closed for unmet source policy. This tests a static gate, **not** a simulated external attack or online signature verifier.
