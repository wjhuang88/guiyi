## Failure and review checks

- **No silent policy upgrade:** Full audited Undo/Redo, concurrency/multi-writer locking, content/save migrations, UI approval client and actual model-selected Talos session are not described as shipped. A new normative guarantee requires its owning Story and possibly a superseding ADR, not an ENG-028 wording change.
- **No false green CI:** Record actual final implementation commit and run IDs on PR; `cargo fmt/check/clippy/test/doc`, Python repository/architecture/docs/static/reproducibility checks and mainline examples must all pass as configured. This report tracks those results separately from human acceptance.
- **No implicit ownership drift:** Talos remains the provider/turn/planning/lifecycle runtime. GUIYI holds authoritative game content, typed Commands/Queries, security, diagnostics, build, preview, storage. The Human Editor is secondary, not an authoring truth.
- **No ungrounded scalability guarantee:** ADRs note current clone/hash, graph refresh, artifact loop costs and unknown size/performance ceilings without invented benchmarks or operational SLAs.
- **Human reviewer:** Independently verify the ten documents against linked source/test behavior and the original ADRs, using [the separate checklist](ENG-028-MANUAL-ARCHITECTURE-REVIEW.md). A newly discovered policy conflict should be recorded as FAIL/BLOCKED with owning Issue; never patch engine code outside this Story.
