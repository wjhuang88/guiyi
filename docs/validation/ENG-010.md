## Compatibility and migration evidence

- Public dialect version is `1` and is emitted as `x-schema-version`.
- Nested version markers, when present, must match the root version.
- Previously valid command inputs remain valid.
- `document.create.payload` defaults to `null`.
- `document.create.schema_version` defaults to `1`.
- Tactical command object and array defaults are schema-driven.
- Additional properties are allowed by default in dialect v1.
- Explicit null on a non-nullable node is always rejected.
- `SchemaNode` and `SchemaDefinition` extensions both require `x-guiyi-*`.
- Envelope extensions are validated before registry insertion.
- All eight command capability schemas are golden-tested against the runtime authority.

## Rollback evidence
