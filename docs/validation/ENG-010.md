## Required fixtures

Schema-definition fixtures:

- unknown ordinary constraint keyword;
- namespaced `x-guiyi-*` extension;
- duplicate field name;
- minimum greater than maximum;
- string constraint on a numeric field;
- invalid default;
- unsupported schema version;
- nested array item schema.

Command-input fixtures:

- missing required root field;
- wrong root kind;
- wrong scalar kind;
- explicit null on non-nullable and nullable fields;
- enum mismatch;
- below/above numeric bound;
- below/above string length;
- below/above array length;
- duplicate item when uniqueness is required;
- invalid nested item with a path such as `/path/0`;
- unknown property when `additionalProperties` is false;
- omitted field receiving a schema default.

Migration fixtures:

- `document.create` default `schema_version` remains `1`;
- `document.set_field` rejects an empty `path` structurally;
- `stage.create` rejects zero dimensions structurally;
- tactical array/object inputs retain valid behavior;
- domain-semantic failures such as duplicate IDs remain command-specific diagnostics.
