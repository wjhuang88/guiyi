## Compatibility and migration

ENG-029 changes approved direction and documentation only. It intentionally does not change Rust APIs or dependencies.

ENG-014 owns the implementation migration. It must:

- add the registry-sourced `talos-runtime` dependency at an outer integration boundary;
- prefer one direct Talos dependency and public SDK re-exports;
- adapt live GUIYI capabilities to Talos `AgentTool` registrations through `RuntimeBuilder`;
- preserve GUIYI domain permission, working-set, validation, transaction, diagnostic and persistence enforcement;
- define compatibility/deprecation for `AgentLoopDriver` and overlapping Agent lifecycle state;
- record pre-1.0 Talos version/feature migration impact.
